Portafolio Interactivo - PC3

Descripción

Página web desarrollada para la Práctica Calificada 3 del curso Hojas de Estilo en Cascada Avanzado.

Tecnologías utilizadas

HTML5

CSS3

Bootstrap 5.3.3

Componentes Bootstrap

Barra de navegación responsiva con menú hamburguesa.

Sistema Grid para organizar los proyectos.

Tarjetas para mostrar proyectos.

Formulario de contacto con campos Nombre, Email y Mensaje.

Botones Enviar y Limpiar.

Transformaciones 2D

rotate(5deg): rotación de la primera tarjeta.

scale(1.08): aumento de tamaño de la segunda tarjeta.

translateY(-15px): desplazamiento de la tercera tarjeta.

transition: permite que los cambios sean suaves.

Transformación 3D

Se implementó una tarjeta con perspectiva que gira al pasar el mouse, utilizando perspective, transform-style: preserve-3d, rotateX() y rotateY().

Animaciones CSS

@keyframes aparecer: anima la entrada del título principal.

@keyframes girar: crea un loader circular con rotación infinita.

Diseño responsivo

Se utilizó Bootstrap Grid para adaptar el contenido a computadoras, tablets y celulares.
